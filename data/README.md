# Data instructions

The planned source is the UCI Online Retail dataset:
https://archive.ics.uci.edu/dataset/352/online-retail

Keep original downloaded files in `data/raw/` and derived cleaned/feature datasets in `data/processed/`. These directories are ignored by Git to avoid committing large data files. In Colab, the dataset can instead be read from Google Drive.

Do not upload secrets, private customer data, or the raw dataset to the public repository.
